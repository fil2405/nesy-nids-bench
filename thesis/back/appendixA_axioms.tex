\chapter{Full axiom set in Real Logic}
\label{app:axioms}

This appendix lists the axioms of the knowledge bases described in
\cref{sec:kb-format}. A row with conditions $C_1,\dots,C_k$ and target class $T$
is the axiom $\forall x\,\bigl(C_1(x)\wedge\dots\wedge C_k(x)\rightarrow
T(x)\bigr)$ over the classified units. An equality is a crisp predicate, and a
comparison with a threshold is graded with the width of the file or crisp, as the
run asks.
